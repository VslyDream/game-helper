# Компоновка сайта

Главное — привычные места и плотность. Это общий стандарт интерфейса для выбранной игры.

## Схема обычного окна

```text
┌──────────────────────┬──────────────────────────────────────────────────────┐
│ 🎮 Название хелпера   │ ● Игра подключена        [Запустить] [Закрыть]       │
│ Название игры        ├──────────────────────────────────────────────────────┤
│                      │ Читы                              Хост / клиент      │
│ 🎮 Читы              │                                                      │
│ 💾 Сохранения        │ 🎥 Камера                  [Ctrl+P / Num9]     [вкл] │
│ 🎬 Записи и повторы  │ Скорость   [────●──] 0,1   FOV [───●──] 82°         │
│                      │ Чувствит.  [──●────]       Плавность полёта [──●─]   │
│   🎥 Камера          │ Плавность поворота [──●──]                           │
│   🧍 Категория       │ ▸ 🔭 Оптика и глубина резкости                       │
│   🌍 Категория       │                                                      │
│   🎨 Категория       │ 🧍 Группа функций          🌍 Группа функций         │
│                      │ Название       [вкл]      Число [ 100 ] [Действие]   │
│                      │ Параметр [──●──] 25       Выбор [ вариант ▾ ]        │
│                      │                                                      │
│ версия               │ [Короткое сообщение только при необходимости]       │
└──────────────────────┴──────────────────────────────────────────────────────┘
```

Пункты необязательных модулей отсутствуют, если они не включены. Список вложенных категорий относится к странице «Читы». Их названия и содержимое определяются проектом.

## Что видно сразу и что свёрнуто

| Место | Всегда видно | В дополнительном меню |
|---|---|---|
| Общая оболочка | Подключение, запуск/закрытие игры, страницы | Техническая диагностика, установка PWA — без большой постоянной плашки |
| Камера | Включение, скорость, FOV, чувствительность, две плавности | «Оптика и глубина резкости» |
| Оптика, когда раскрыта | Фокус, точка фокуса, один регулятор диафрагмы; при поддержке компактная строка «Объектив: … мм» | Без дополнительного вложенного меню для объектива |
| Сохранения | Создание, прохождение, галерея, загрузка, импорт, корзина | «•••»: название, экспорт, в корзину; отдельный блок последнего файла на диске |
| Повторы | Запись/пауза/стоп, загрузка, старт, сначала, скорость, время, таймлайн | Вторичные действия карточки; дорожки рядом с соответствующим повтором |
| Игровой чит | Основной контрол и результат | Редкие параметры конкретной функции |

Не прятать повседневную работу в несколько вложенных меню. Не выводить все редкие настройки постоянными длинными блоками.

В рабочей панели не нужны декоративные метки «Пример проекта» и «пример» рядом со статусом. Самостоятельная демонстрация помечается один раз снаружи рабочего интерфейса либо в нижней строке, без повторяющихся ярлыков на карточках.

## Плотность как проверяемый критерий

- Слева компактная колонка примерно 200–240 px; главное содержимое использует оставшуюся ширину.
- Ориентир для карточек: внутренние отступы 14–18 px, промежутки 12–16 px; не крупные промоблоки.
- Короткий ползунок обычно занимает 180–320 px на настольном экране, а не всю ширину окна. Связанные настройки — в двух–трёх колонках, когда это читаемо.
- Числовое поле обычно 72–100 px. Контролы высотой около 32–36 px, текст обычных подписей около 13–14 px. Числа — с единицами и предсказуемым форматом.
- Необязательно умещать произвольное число читов без прокрутки. Требование — одна страница с секциями и высокой полезной плотностью, не превращение каждой секции в отдельный экран.
- При уменьшении ширины сетка перестраивается. Не допускаются перекрытия, исчезающие подписи и горизонтальная прокрутка всей страницы.

Числа — ориентиры для каркаса, а не повод ломать удобство в конкретном окне.
