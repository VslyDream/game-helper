# 6. Распространение — необязательный черновой модуль

Включать только по запросу. Этот модуль нужен, если хелпером будут делиться, переносить его на другой компьютер или публиковать на GitHub. Он не требуется для личной локальной разработки. Части выбираются независимо.

| Опция | Результат |
|---|---|
| Переносимый пакет | Полный архив, зависимости и короткая инструкция запуска |
| Установщик | Простой установщик, если он нужен выбранной игре и аудитории |
| Поиск игры | Автоопределение папки игры или однократный выбор пути |
| GitHub | Репозиторий, осмысленные коммиты, версии и при необходимости релизные архивы |

- **DIST-01. Пакет.** Если выбран: другой пользователь получает комплект без необходимости собирать проект или разыскивать неуказанные зависимости. Инструкция соответствует реально проверенному способу запуска.
- **DIST-02. Установщик.** Если выбран: устанавливает только компоненты данного хелпера. Путь с пробелами и кириллицей поддерживается. Данные пользователя отделены от заменяемой программы по обязательному CORE-16.
- **DIST-03. Поиск игры.** Если выбран: доступные библиотеки/платформы проверяются автоматически, иначе путь выбирается один раз и запоминается. Личные абсолютные пути автора не зашиты в пакет.
- **DIST-04. Чистая копия.** В распространяемую папку не попадают личные игровые сохранения, галереи, скриншоты, дампы, токены и настройки с личными путями. Примеры отделены от пользовательских данных.
- **DIST-05. GitHub.** Если выбран: изменения оформляются понятными коммитами, версии согласованы в коде и названии пакета; опубликованный тег указывает на соответствующий коммит. Если нужен Release, к нему прикладывается проверенный полный архив и краткий список изменений. Адрес репозитория, видимость и необходимость публикации определяются пользователем; сам выбор модуля не разрешает публикацию.

Это отправная точка, а не универсальная система доставки. Автообновление, откаты, матрицы совместимости и сложные установщики не входят в стандарт; добавляются только отдельным требованием.

Приёмка — по выбранным опциям: запуск чистой копии в другом пути, отсутствие личных данных в архиве и соответствие опубликованной версии исходникам. Не обещать проверку на другом компьютере, если проверялся только другой каталог.
