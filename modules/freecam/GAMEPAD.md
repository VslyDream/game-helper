# 3а. Геймпад для фрикамеры — дополнительная опция

Читать и подключать только при выборе геймпада. Требует модуля фрикамеры. Наличие этой опции не требует поддержки геймпада от каждого нового проекта.

Общее считывание и SVG-диагностика вынесены в независимый модуль
[`controller`](../controller/SPEC.md): проверенный Windows/XInput-провайдер,
нормализация, мёртвая зона, раздельные курки и жизненный цикл устройства.
Читай его [контракт](../controller/ADAPTER.md) перед собственной реализацией ввода,
если используешь этот путь. Диагностическую страницу включай только явным
выбором `controller`; наличие `gamepad` не включает её автоматически.

Чтение не поглощает ввод игры. Мод отдельно подавляет штатные действия персонажа
на время камеры и восстанавливает их при выключении. Не рассчитывай, что
браузерная вкладка останется открытой или будет получать ввод поверх игры:
игровое управление реализуется в адаптере, независимо от сайта.

Основная раскладка Xbox-совместимого контроллера — **«Операторская»**: зум и фокус на курках, как на пульте оператора. Выбрана владельцем и опробована им на настоящем контроллере в одном проекте.

| Ввод | Действие | Переназначается |
|---|---|---|
| View / Back + Y | Включение/выключение фрикамеры | да, общий хоткей |
| Левый стик | Полёт вперёд/назад и в стороны | нет |
| Правый стик | Обзор | нет |
| RT / LT | Вверх / вниз | нет |
| A | Точка фокуса: закрепить / отпустить | да |
| R3 | Ускорение поворота ×5, пока держишь | да |
| L3 | Ускорение полёта ×5, пока держишь | да |
| LB + RT / LT | Зум ближе / дальше, плавно по силе нажатия | да, кнопка LB |
| RB + RT / LT | Фокус дальше / ближе; ручной фокус снимает фиксацию точки | да, кнопка RB |
| Крестовина ↑ / ↓ | Скорость полёта быстрее / медленнее | да |
| Крестовина → / ← | Диафрагма шире (больше размытия) / уже | да |

Пока зажат LB или RB, курки не двигают камеру по вертикали; LB и RB вместе — курки ничего не делают; полёт стиками при зуме и фокусе не останавливается. Переназначаемые кнопки камеры живут отдельным разделом списка хоткеев «Камера на контроллере» (`contracts/adapter.md`): клавиатурной привязки у них нет, стики и курки стоят в разделе закреплёнными строками. Ориентиры скоростей из того же проекта, отдельно не подтверждались: зум до 30°/с при полном нажатии, фокус ×2,5 в секунду, шаг диафрагмы раз в 0,3 с.

Если у свободной камеры нет размытия фона (`freecam.optics: false`), строки точки фокуса, фокуса и диафрагмы из раскладки и из раздела убираются; остальное не меняется.

Учитывать мёртвую зону, чувствительность и удержание комбинаций; переключение не повторяется каждый кадр. Ввод прекращается при потере фокуса. Клавиатура и геймпад согласованно изменяют одни настройки. При отключении камеры возвращается штатное управление геймпадом.

Упрощённый вариант — прежняя схема набора, если плавный зум на курках делать не стали: RB / LB — скорость быстрее / медленнее, нажатие левого стика — ускорение ×5, крестовина вверх / вниз — FOV; стики и курки те же.

Приёмка: проверить реальным контроллером подключение, отключение, оба стика, триггеры, комбинацию включения, потерю фокуса и возврат в игру. Эмуляция входных событий не выдаётся за проверку устройства.
