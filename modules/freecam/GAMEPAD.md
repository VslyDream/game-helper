# 3а. Геймпад для фрикамеры — дополнительная опция

Читать и подключать только при выборе геймпада. Требует модуля фрикамеры. Наличие этой опции не требует поддержки геймпада от каждого нового проекта.

Общее считывание и SVG-диагностика вынесены в независимый модуль
[`controller`](../controller/SPEC.md): проверенный Windows/XInput-провайдер,
нормализация, мёртвая зона, раздельные курки и жизненный цикл устройства.
Читай его [контракт](../controller/ADAPTER.md) перед собственной реализацией ввода,
если используешь этот путь. Диагностическую страницу включай только явным
выбором `controller`; наличие `gamepad` не включает её автоматически.

Чтение не поглощает ввод игры. Мод отдельно подавляет штатные действия персонажа
на время камеры и восстанавливает их при выключении. Не рассчитывай, что
браузерная вкладка останется открытой или будет получать ввод поверх игры:
игровое управление реализуется в адаптере, независимо от сайта.

Привычная схема Xbox-совместимого контроллера:

| Ввод | Действие |
|---|---|
| View / Back + Y | Включение/выключение фрикамеры |
| Левый стик | Полёт вперёд/назад и в стороны |
| Правый стик | Обзор |
| RT / LT | Вверх / вниз |
| RB / LB | Быстрее / медленнее |
| Нажатие левого стика | Ускорение ×5 |
| Крестовина вверх / вниз | FOV |

Учитывать мёртвую зону, чувствительность и удержание комбинаций; переключение не повторяется каждый кадр. Ввод прекращается при потере фокуса. Клавиатура и геймпад согласованно изменяют одни настройки. При отключении камеры возвращается штатное управление геймпадом.

Второй, необязательный вариант — раскладка **«Операторская»**: зум и фокус на курках, как на пульте оператора. Предлагать, если с геймпада снимают подолгу. Опробована владельцем на настоящем контроллере в одном проекте.

| Ввод | Действие |
|---|---|
| Стики, RT / LT, View + Y | Как в привычной схеме; стики и курки не переназначаются |
| LB + RT / LT | Зум ближе / дальше, плавно по силе нажатия |
| RB + RT / LT | Фокус дальше / ближе; ручной фокус снимает фиксацию точки |
| L3 / R3 | Ускорение полёта / поворота ×5, пока держишь |
| A | Точка фокуса: закрепить / отпустить |
| Крестовина ↑ / ↓ и → / ← | Скорость полёта; диафрагма шире / уже |

Пока зажат LB или RB, курки не двигают камеру по вертикали; LB и RB вместе — курки ничего не делают. Все кнопки, кроме стиков и курков, переназначаются в разделе списка хоткеев (`contracts/adapter.md`); клавиатурной привязки у них нет. Ориентиры скоростей из того же проекта, отдельно не подтверждались: зум до 30°/с при полном нажатии, фокус ×2,5 в секунду, шаг диафрагмы раз в 0,3 с.

Приёмка: проверить реальным контроллером подключение, отключение, оба стика, триггеры, комбинацию включения, потерю фокуса и возврат в игру. Эмуляция входных событий не выдаётся за проверку устройства.
