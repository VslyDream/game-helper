# Справочник

Подключаемый модуль. Нужен, только если выбранные читы выдают или создают что-то по id: предметы в инвентарь, ресурсы для крафта, юниты, транспорт, NPC. Без таких читов не подключается.

## Зачем

Агенту и панели нужно один раз узнать, как в игре называются вещи, и больше не искать их заново. Пользователь говорит «сотри инвентарь, выдай всё для такого-то крафта» или «дай три аптечки», агент находит id в справочнике и вызывает чит.

## Требования

- **CAT-01. Один раз на проект.** Справочник собирается агентом при исследовании игры и записывается в файл проекта `catalog/<name>.json` внутри сайта. После обновления игры он сверяется с игрой (самопроверка CORE-22) и дополняется, а не собирается с нуля.
- **CAT-02. Запись.** `{"id": "medkit_small", "name": {"en": "Small Medkit", "ru": "Малая аптечка"}, "aliases": ["аптечка", "хилка"], "group": "Медицина", "icon": "icons/medkit_small.png"}`. `id` — тот, что понимает адаптер. Названия — как в игре на обоих языках. `aliases` — как это назовёт человек голосом. `icon` — если иконку можно достать из игры; без неё запись тоже полная.
- **CAT-03. Рецепты по желанию.** Если игра знает крафт, в справочнике можно хранить рецепты `{"id": "...", "result": "...", "needs": [{"id": "...", "count": 2}]}`, чтобы выдать «всё для крафта» одной командой.
- **CAT-04. Выбор в панели.** Контрол `"type": "pick"` с `"catalog": "<name>"` показывает поле с поиском по названиям и синонимам, иконки в списке, количество при `count`. Отправляет `cheat.run {id, values:{item, count}}`.
- **CAT-05. Только чтение.** Справочник описывает игру и не меняет её. Неизвестный игре id в справочнике помечается при самопроверке, а не ломает чит.

## Пример контрола

```json
{"id": "giveItem", "label": "Выдать предмет", "type": "pick", "catalog": "items",
 "count": {"min": 1, "max": 999, "step": 1, "value": 1, "label": "Сколько"}}
```

## Приёмка

1. Поиск в панели находит запись по русскому, английскому названию и синониму.
2. Агент из чата выдаёт предмет по разговорному названию, не изучая игру заново.
3. После обновления игры самопроверка показывает исчезнувшие id.
