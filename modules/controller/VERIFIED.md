# Проверенная конфигурация

9 ноября 2026 года. Стенд `controller-lab`, Windows, Flydigi Direwolf 4 по USB.

- [V, Windows] Устройство `USB\VID_045E&PID_028E\FLYDIGI_DIREWOLF_4`,
  «Контроллер Xbox 360 для Windows», XnaComposite, статус OK.
- [V, API] `xinput1_4.dll`, слот 0: обычные кнопки и направления крестовины,
  движение обоих стиков, диапазоны осей около −1…1, раздельные курки 0…1
  с промежуточными значениями, оба курка одновременно, отключение/подключение USB.
- [V, пользователь] Пользователь подтвердил совпадение показаний с действиями,
  включая View/Back, Menu/Start, L3/R3, полный круг левым стиком,
  оба курка одновременно и переподключение USB. Нажатия L3/R3 подтверждены
  пользователем; на момент сохранения серверного отчёта они не были в маске наблюдений.
- [V, ПО] Отдельный поток Windows обслуживает API независимо от вкладки.
  Накопленные отсчёты и аппаратные наблюдения доступны из другого процесса.
- [V, ПО] На Python 3.14 после исправления таймера измерено около 116 циклов/с
  при целевых 120. Сгенерированный проект с `controller` поднимает живой API;
  без него нет UI-файлов, провайдера, требований и фонового опроса.
  Пройдены 16 автоматических тестов стенда и интеграции; страница и настройка
  мёртвой зоны проверены в сгенерированной оболочке.

Сначала устройство не было обнаружено. Пользователь нажал Home несколько раз,
после чего Windows начала его видеть. Агент не менял режим, драйверы или прошивку.
Пробуждение по Home — вероятное объяснение [I], точный причинный сценарий не установлен.

## Не подтверждено этой проверкой

- Беспроводной приёмник и Bluetooth; другие модели, режимы и версии прошивки.
- Совпадение всех физических кнопок через браузерный Gamepad API.
- Непрерывное физическое движение с закрытыми всеми вкладками и переключением
  игровых окон: фоновый поток проверен, полный пользовательский сценарий отдельно не отмечен.
- Отдельные задние кнопки, Home/Guide, гироскоп и вибрация.
- Камера и подавление штатного ввода в любой конкретной игре.
