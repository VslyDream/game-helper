# Игровой хелпер

Папка для передачи агенту. По ней агент изучает игру, предлагает, что в ней можно сделать для съёмки, и собирает локальную панель читов с модом. Вам не нужно писать код и заново объяснять оформление: требования, хоткеи и шаблон сайта лежат внутри.

## Как пользоваться

Передайте **всю папку**, назовите игру и нужные функции:

```text
Используй папку game-helper, начни с SKILL.md.
Игра: …, папка: …
Нужны фрикамера с оптикой и сохранения. Повторы и геймпад не нужны.
Читы: …
```

Вместо сообщения можно заполнить [PROJECT.md](PROJECT.md). После изучения игры агент покажет короткий список того, что в ней доступно сверх заказанного, и ничего из него не сделает без вашего выбора.

Папку можно приложить как обычное вложение или подключить как скилл `game-helper`.

## Что внутри

| Где | Что |
|---|---|
| `SKILL.md` | Маршрут агента по этапам: исследование → предложения → сайт и адаптер → приёмка |
| `PROJECT.md` | Заявка: игра и нужные модули |
| `references/` | Правила: запуск, интерфейс, компоновка, процесс, исследование игры, известные грабли |
| `references/engines/` | Знания по движкам: Unity IL2CPP и Mono, Unreal |
| `modules/` | ТЗ необязательных модулей и их общий состав `manifest.json` |
| `contracts/` | Граница между сайтом и модом конкретной игры |
| `assets/site/` | Шаблон панели |
| `templates/` | Заготовки документов проекта, плагина Unity и инструментов агента |
| `scripts/` | Разведка игры, сборка проекта из выбранных модулей, локальный просмотр |
| `tests/` | Проверки самого набора |

Шаблон панели **не содержит интеграции с игрой**: её агент пишет для каждой игры отдельно. Деморежим показывает только интерфейс и помечен в нижней строке панели.

## Посмотреть панель без игры

Нужен Python 3:

```text
python scripts/create_project.py --name "Мой хелпер" --id my-game --modules freecam,snapshots --demo --output ../my-game-helper
python ../my-game-helper/serve.py --port 18767
```

Открыть `http://127.0.0.1:18767/`. Флаги `--modules` — из первого столбца таблицы в [SKILL.md](SKILL.md); у невыбранных модулей в результате нет ни интерфейса, ни ТЗ. Без `--demo` создаётся проект для настоящего подключения, `--engine unity-il2cpp` добавляет каркас плагина. Разведку игры можно запустить отдельно: `python scripts/recon.py "<папка игры>"`.
