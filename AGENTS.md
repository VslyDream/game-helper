# Работа с этой папкой

Переносимый набор требований, знаний и заготовок игрового хелпера. Начни с `SKILL.md` — там маршрут по этапам — и заявки пользователя / `PROJECT.md`.
Не читай папку рекурсивно: документы этапа и только выбранные модули. История изменений — в git этой папки.
Проверка набора после правок: `python -m unittest discover -s tests` и `node --test tests/hotkeys.test.mjs`.
