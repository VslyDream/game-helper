# 7. Управление из чата (MCP)

Подключаемый модуль без своей страницы. Агент в чате управляет игрой теми же командами, что и панель: пользователь диктует «загрузи такой-то момент, включи бессмертие, давай ещё раз», агент выполняет и показывает кадр.

## Поведение

- **MCP-01. Одни команды на двоих.** MCP-сервер не дублирует логику: он вызывает тот же локальный API (`/api/action`, `/api/state`), что и сайт. Новая команда адаптера сразу доступна и в панели, и в чате.
- **MCP-02. Без перезапуска.** Список инструментов MCP строится из `GET /api/commands` адаптера. Добавленный чит или команда появляются у агента после пересборки мода, без перезапуска MCP-сервера и чата. Если клиент MCP кеширует список, есть общий инструмент `run {command,args}` и `commands` (список с описаниями), чтобы новая команда была доступна сразу.
- **MCP-03. Кадр в чат.** Инструмент `screenshot` возвращает текущий кадр игры картинкой, по желанию уменьшенный. Агент проверяет им результат, прежде чем сказать «готово».
- **MCP-04. Ожидание готовности.** `wait_ready {timeout}` ждёт, пока игра запустится, загрузит уровень или закончит операцию. Агент не гадает паузами.
- **MCP-05. Пауза видна всегда.** В каждом ответе инструментов есть короткая строка состояния: подключение, сцена, пауза и скорость времени. Так агент не путает «игра зависла» с «стоит на паузе».
- **MCP-06. Описания для голоса.** Описание каждой команды и чита — обычными словами, с синонимами, которыми пользователь может её назвать («скрыть интерфейс», «убрать HUD»). При подключённом справочнике агент ищет id по нему, а не перебирает игру заново.
- **MCP-07. Те же ограничения.** Команда, недоступная в панели, недоступна и в чате, с той же причиной. Агент не обходит недоступность прямыми вызовами.

## `GET /api/commands`

```json
[
  {"command": "cheat.set", "id": "hideUi", "title": "Скрыть интерфейс игры",
   "aliases": ["убрать HUD", "чистый кадр"], "args": {"value": "boolean"}},
  {"command": "snapshots.retake", "title": "Дубль заново",
   "aliases": ["давай ещё раз", "перезагрузи сцену"], "args": {}}
]
```

Список строится из `config.json → cheats` и команд выбранных модулей; адаптер дополняет его своими командами. Доступность берётся из `state.availability`.

## Приёмка

1. Новый чит, добавленный в адаптер, вызывается из чата без перезапуска MCP-сервера.
2. `screenshot` и `wait_ready` работают при закрытой игре, в меню и на уровне, с понятным ответом в каждом случае.
3. Ответ при паузе и скорости ×0 прямо говорит об этом.
