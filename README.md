# Игровой хелпер

Готовая папка для передачи агенту. Согласованный стандарт от 29 октября 2026 года, дополнен 7 ноября 2026 года; распространение — отдельный черновой модуль.

Передайте **всю эту папку**, укажите игру и нужные функции. Например:

```text
Используй папку game-helper, начни с SKILL.md.
Игра: …, папка: …
Нужны фрикамера с оптикой и сохранения. Повторы и геймпад не нужны.
Читы: …
Распространение пока не нужно.
```

Можно заполнить [PROJECT.md](PROJECT.md). Уточнять оформление заново не нужно: требования, хоткеи и шаблон сайта уже лежат внутри. Агент читает только выбранные модули.

| Где | Что внутри |
|---|---|
| `SKILL.md` | Короткая инструкция для агента и выборочное чтение |
| `references/` | Правила запуска, UI, компоновки, процесса разработки; [исследование игры](references/research.md), [грабли](references/pitfalls.md) |
| `references/engines/` | Плейбуки движков: определение Unity, IL2CPP + BepInEx 6, Mono + BepInEx 5, где что искать, Unreal + UE4SS |
| `templates/` | Заготовки `docs/` и журнала, каркас плагина Unity IL2CPP, цикл сборки и CLI агента |
| `modules/` | Отдельные ТЗ фрикамеры, сохранений, повторов, справочника, постановки, MCP и распространения |
| `contracts/` | Граница между сайтом и конкретной игрой |
| `assets/site/` | Общая оболочка и раздельные элементы сайта |
| `scripts/` | Разведка игры (`recon.py`), сборка выбранного состава и локальный просмотр |
| `project.example.json` | Пример настроек генератора; изначально только основа |

Шаблон сайта включает рабочую навигацию, компактные контролы, галерею с корзиной и панель повторов. Он **не содержит интеграцию с неизвестной игрой**: её агент пишет отдельно. Деморежим хранит только примеры в браузере и явно отмечен. Настоящий режим использует локальный API, отключает недоступные действия и не выдаёт макет за игровой результат.

[Образец интерфейса](assets/interface-preview.png). Подписи и состояние на изображении демонстрационные; источником требований остаются раздельные ТЗ.

Для просмотра выбранного состава без сторонних библиотек нужен Python 3:

```text
python scripts/create_project.py --name "Мой хелпер" --id my-game --modules freecam,snapshots --demo --output ../my-game-helper
python ../my-game-helper/serve.py --port 18767
```

Открыть `http://127.0.0.1:18767/`. Команды — удобство для агента; пользователю не требуется самому собирать сайт. Без `--demo` создаётся режим настоящего подключения. Можно использовать `--profile project.example.json`.

Необязательные флаги состава: `freecam`, `gamepad`, `snapshots`, `replay-camera`, `replay-players`, `catalog`, `staging`, `mcp`, `distribution`. Страница «⚙ Настройки» есть всегда. У выключенных модулей в результате нет файлов интерфейса, пунктов меню и ТЗ. `--modules` задаёт точный состав; зависимости проверяются, а не включаются молча.

Каждый проект получает заготовки `docs/` (матрица возможностей, журнал `MODLOG.md`, карточка игры), `tools/` (разведка `recon.py`, цикл сборки, CLI агента) и правила исследования в `requirements/`. `--engine unity-il2cpp` дополнительно кладёт в `adapter/` каркас плагина BepInEx 6 IL2CPP. Разведку можно запустить и до создания проекта: `python scripts/recon.py "<папка игры>"`.

Папку можно использовать как обычное вложение или как скилл `game-helper`, если агент поддерживает скиллы. Установка в личные настройки не требуется.
